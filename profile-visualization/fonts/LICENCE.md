# Familjen Grotesk

Familjen Grotesk by Nikolas Type, released under the SIL Open Font License 1.1.
Free for commercial and personal use, including self-hosting as it is here.

Listed on Fontshare (https://www.fontshare.com/fonts/familjen-grotesk). The
woff2 files in this folder came from the Fontsource build on npm
(@fontsource/familjen-grotesk), because the Fontshare CDN is not reachable from
the build environment. Same typeface, Latin subset, weights 400/500/700.

Chosen against the criteria in Datawrapper's "Fonts for data visualization":
a normal-width sans, regular and medium weights for text with bold reserved for
emphasis, and - the deciding property - tabular lining figures. Familjen
Grotesk's digits are all the same width by default, with no OpenType feature
flag needed, which matters here because font-variant-numeric is unreliable on
SVG <text> across browsers.
